# 📝 Blog Website

Welcome to the **Blog Website**, a beautifully designed, responsive, and performance-optimized blog platform developed using **Next.js 13 (App Router)** and **Tailwind CSS**. This project serves as both a learning resource and a functional portfolio piece for developers interested in modern web development using React-based frameworks.

🌐 **Live Preview**: [https://blogwebsite-gray.vercel.app](https://blogwebsite-gray.vercel.app)

---

## 📖 About the Project

This blog platform showcases how to structure and build a scalable web application using the latest technologies in the frontend ecosystem. It allows users to read well-presented content in a clean, readable layout. Though currently static, it can be expanded into a dynamic, CMS-powered blog with minimal effort.

The aim of this project is to demonstrate core frontend development concepts such as:

- Routing and navigation using Next.js App Router
- Styling and responsive design with Tailwind CSS
- File-based structure and reusable components
- Performance best practices with server-side rendering (SSR)
- Clean UI/UX suitable for personal blogs, portfolios, or company blogs

---

## 🚀 Key Features

- ✅ **Modern Tech Stack**: Built with Next.js 13, React 18, Tailwind CSS, and Vercel for deployment
- 📱 **Responsive Design**: Mobile-first design ensures the blog looks great on all devices
- 🧱 **Reusable Components**: Navbar, footer, and blog card components keep the code modular
- 📂 **Structured App Routing**: Utilizes Next.js app directory structure for clean, scalable navigation
- ⚙️ **Easy Customization**: Ready to plug into any CMS like Sanity, Strapi, or Contentful
- 🔒 **SEO-Optimized**: Out of the box optimization thanks to Next.js framework
- ☁️ **Live on Vercel**: Fast deployment and global CDN hosting for best performance

## 🛠️ Getting Started

### 🔧 Prerequisites

Make sure you have these tools installed:

- **Node.js** (v18 or higher)
- **npm** (or yarn, pnpm)

### 📦 Installation Steps

Clone the repository and install dependencies:

```bash
git clone https://github.com/muhammadsami987123/Blog-website.git
cd Blog-website
npm install
```

### ▶️ Start Development Server

```bash
npm run dev
```

Visit `http://localhost:3000` in your browser to view the app.

---

## 🌍 Deployment

This project is deployed on **Vercel**, but you can deploy your own version by following these steps:

1. Fork or clone this repository.
2. Visit [vercel.com](https://vercel.com) and import the project from GitHub.
3. Vercel will automatically build and deploy your app from the main branch.
4. Done! Your blog is now live.
